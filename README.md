# 🏎️ Dodge Challenger SRT Hellcat — Landing Page

An aggressive, modern, and fully responsive landing page designed to showcase the power and engineering of the **DODGE Challenger SRT Hellcat**. Built with speed, performance, and visual impact in mind.

![Dodge Challenger SRT Hellcat Preview](https://images.unsplash.com/photo-1552519507-da3b142c6e3d?w=1200&q=85)

---

## 🔥 Features

*   **Hero Section with Speed Effects:** Includes dynamic gradients, background speed lines, and real-time floating performance specs.
*   **Interactive Sound Simulator:** Custom-designed audio waveform visualizer for the engine exhaust roar with play/pause progress tracking.
*   **Dynamic Specs Switcher:** Tabbed interface switching between *Powertrain*, *Performance*, and *Dimensions* without page reloads.
*   **Interactive Visual Gallery:** Modern CSS grid layout highlighting exterior and interior angles with smooth hover effects.
*   **Test Drive Reservation Form:** Fully styled booking form with auto-validated date inputs and location pickers.
*   **Mouse-Tracking Glow:** Custom radial glow effect that seamlessly follows the user's cursor on desktop screens.
*   **Fully Responsive:** Optimized for desktop, tablet, and mobile viewing with smooth scrolling transitions.

---

## 🛠️ Tech Stack

*   **Structure:** HTML5
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (via CDN) + Custom CSS3 Animations
*   **Typography:** Google Fonts (*Anton*, *Oswald*, *Barlow*)
*   **Icons:** [Font Awesome 6](https://fontawesome.com/)
*   **Scripting:** Vanilla JavaScript (ES6+)
